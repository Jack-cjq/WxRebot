# Examples

当前仓库已精简为“微信群聊记账机器人”最小示例集：

- `python examples\messaging\start_bookkeeping_robot.py`
  - 一键启动（控制面板 + 机器人监听）。
- `start_bookkeeping_robot.bat`
  - Windows 双击一键启动入口。
- `python examples\messaging\group_bookkeeping_panel.py`
  - 控制面板（查看监听群、配置白名单、设置指令触发词、手动加群）。
- `python examples\messaging\group_bookkeeping_bot.py`
  - 机器人监听主程序。

统一配置文件：

- `examples\messaging\group_bookkeeping_config.json`
